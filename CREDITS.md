# Credits

## Artwork

**Brick the mouse** — the three sprites in `assets/`: `brick-sit.png`,
`brick-grab.png`, `brick-eat.png`.

These are someone else's artwork, used with credit. `brick-grab.png` carries
the artist's signature, and **that is deliberate and must not be edited out** —
it's how they're credited. I haven't traced the original post yet; when I do,
their name and a link go here.

**The squish clip** — `assets/brick-squish.mp4` (and a `.webm` copy for
browsers without H.264), the "mmmh yes squishy rat" clip the squish button
plays. The drawing in it is Brick, so the credit above covers that. Where the
clip itself was first posted, including the photo it's composited onto, isn't
known yet.

Everything else drawn on this site is original: the Windows 98 chrome, the
desktop icons, the cheese block (drawn to match the cheese Brick is holding in
`brick-eat.png`), the respawn clock, and the dithered wallpaper are all
CSS and hand-written SVG made for this project. They are *in the idiom* of
Windows 98 but are not Microsoft's icon files, which are not redistributable.

## Code

Plain HTML, CSS and JavaScript — no framework, no dependencies, nothing
vendored. `build.py` is Python standard library only.

## Inspiration

The early-web, personality-first approach owes a lot to personal sites like
[anemoia.moe](https://anemoia.moe) and [kitsu.red](https://kitsu.red). No code
or assets were taken from them.
