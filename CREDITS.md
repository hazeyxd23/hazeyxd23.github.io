## Code

Plain HTML, CSS and JavaScript — no framework, no dependencies, nothing
vendored. `build.py` is Python standard library only.

## Inspiration

The early-web, personality-first approach owes a lot to personal sites like
[anemoia.moe](https://anemoia.moe) and [kitsu.red](https://kitsu.red). No code
or assets were taken from them.
